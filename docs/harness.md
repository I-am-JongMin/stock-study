# 하네스 — 기계가 지켜주는 것의 단일 장부

> 이 프로젝트에서 **기계가 강제하는 규칙 전부**와 **테스트로 증명하는 것 전부**를 여기 한
> 곳에 적는다. 새 규칙·새 검증이 생기면 코드보다 이 문서를 먼저 고친다 (ADR-023).

두 축은 성격이 다르다.

| | **지키는 것 (가드레일)** | **증명하는 것 (검증)** |
| --- | --- | --- |
| 본질 | 사람의 규율을 기계로 옮긴 것 | 가설이 참인지 실험으로 증명 |
| 언제 | 상시 — 매 빌드·커밋·마이그레이션 | 시점 — 테스트 스위트 실행 때 |
| 깨지면 | 규칙 위반이다 — 코드를 고친다 | 현실이 바뀌었거나 코드가 틀렸다 — 조사한다 |

원칙 — **`./gradlew check` 는 오프라인에서 항상 전부 통과해야 한다.** 외부 세계(키움 서버,
네트워크)가 필요한 검증은 전부 opt-in 태스크로 분리한다. 빌드가 외부 가용성에 인질 잡히는
순간 사람들은 실패를 무시하기 시작하고, 그때부터 하네스는 장식이 된다.

## 1. 지키는 것 — 어기면 빌드·커밋이 죽는다

| # | 규칙 | 왜 | 강제 지점 |
| --- | --- | --- | --- |
| G1 | `core-domain` 에 프레임워크 금지 | 순수해야 속성 기반 테스트가 가능 (ADR-005) | `checkDomainPurity` Gradle 태스크 |
| G2 | 비밀정보 커밋 금지 | 공개 저장소 — 한 번 푸시되면 회수 불가 (ADR-019) | `.githooks/pre-commit` |
| G3 | 비밀정보가 추적 파일에 존재 금지 | G2 는 `--no-verify` 로 우회 가능. 커밋 이전에 이미 들어간 것도 잡아야 한다 | `guardSecrets` Gradle 태스크 (`check` 에 포함) |
| G4 | 실전 도메인(`api.kiwoom.com`) 소스 하드코딩 금지 | 실전 전환은 환경변수 교체로만 (ADR-020/021) | `guardRealTradingDomain` Gradle 태스크 (`check` 에 포함) |
| G5 | 비밀값은 `Secret` 타입으로만 보관 | `toString`·보간·직렬화로 새는 경로를 구조적으로 차단 (ADR-022) | 타입 시스템 + V1 검증 테스트 |
| G6 | INV-1~7 (음수 예수금, append-only, …) | 깨지면 돈이 샌다 (ADR-009) | DB CHECK·트리거·UNIQUE |
| G7 | 원장은 `TRUNCATE` 로도 삭제 불가 | Phase 0 검증에서 발견한 구멍 (ADR-018) | `V2` 트리거 |
| G8 | `instrument.name_chosung` 누락 불가 | 조용한 누락 방지 (ADR-017) | `NOT NULL` 제약 |
| G9 | 키움 원시 필드·DTO 는 `kiwoom/raw` 밖으로 못 나간다 | 부호 달린 `cur_prc` 가 그대로 돌아다니면 음수 가격이 DB 에 들어간다 | `guardKiwoomRawDto` Gradle 태스크 (`check` 에 포함) + `internal` |
| G11 | HTTP 최악 지연 < 토큰 락 TTL | 임계구역이 TTL 을 넘기면 동시 발급이 일어난다 (ADR-024) | `KiwoomProperties` init — 기동 실패 |

- **G10 — 운영 DB 역할 권한 분리**: 트리거는 방지턱이지 권한 경계가 아니다 (ADR-018).

## 2. 증명하는 것 — 테스트 스위트

| # | 스위트 | 증명하는 것 | 외부 의존 | 실행 |
| --- | --- | --- | --- | --- |
| V1 | 비밀 유출 부재 | 카나리아 비밀값을 일부러 흘려도 로그·`toString`·JSON 직렬화 어디에도 평문이 없다 | 없음 | `check` |
| V2 | 단위·속성 | `Money` 연산, 초성(11,172자 전수), 멱등성 속성 | 없음 | `check` |
| V3 | DB 불변식 회귀 | INV-1~7 이 실제 PostgreSQL 에서 막히는지 | Testcontainers | `check` |
| V4 | 계약 | **녹화한 진짜 응답**으로 해석을 증명한다 — HTTP 200 ≠ 성공, `return_code:0` ≠ 데이터 존재, 가격의 부호, `expires_dt` 가 KST 인 것, 읽기 타임아웃, 토큰 거부 시 1회 재시도 | WireMock | `check` |
| V5 | 동시성 — 분산락 | 가상 스레드 100개가 동시에 락을 요구해도 임계구역 진입은 1개. 소유자가 아니면 해제 불가, TTL 초과 시 해제 실패가 **드러난다** (ADR-024) | Testcontainers | `check` |
| V5b | 동시성 — 토큰 | 가상 스레드 50개 동시 요청 → 발급 정확히 1회. 인스턴스가 달라도 공유 캐시로 1회, 선제 갱신이 경합에 져도 서비스는 멈추지 않는다 (§R3) | Testcontainers | `check` |
| V6 | 멱등성 | 종목 동기화 2회 연속 실행 → 행 수 불변 (Phase 1 완료 조건) | Testcontainers | `check` *(예정)* |
| V7 | 라이브 스모크 | **키움이 아직 우리가 아는 모습인가** — 토큰 발급 + 시세 1건 | 진짜 모의서버 + 키 | `liveTest` (opt-in, 키 없으면 skip) *(예정)* |

V7 이 `check` 밖에 있는 이유 — V7 의 실패는 우리 버그가 아니라 **계약 변경 신호**다.
실패하면 픽스처를 다시 녹화하고 V4 가 깨지는 것으로 변경 지점을 찾는다.

## 3. 비밀정보 방어 — 세 겹의 지도

```
경로                           1차 방어 (구조)         2차 방어 (그물)        증명
──────────────────────────────────────────────────────────────────────────────
log.info("$config")      →   Secret.toString = ****                        V1
JSON 응답/로그 직렬화      →   Secret 는 기껏해야 빈 객체({})로 직렬화         V1
외부 응답 원문을 로깅      →                         로그백 마스킹 컨버터     V1
.env 를 git add -f       →   .gitignore            pre-commit 훅 (G2)     수동 검증 완료
yml 에 키 직접 기입       →                         훅 (G2) + guardSecrets (G3)
--no-verify 우회         →                         guardSecrets (G3)
실전 키로 오발급           →   모의 도메인 기본값       guardRealTradingDomain (G4)
```

1차를 뚫으려면 `reveal()` 을 **일부러** 불러야 한다 — 그 호출부는 코드리뷰에서 눈에 띈다.
grep 한 번으로 평문이 나가는 모든 지점을 찾을 수 있다는 뜻이기도 하다:
`grep -rn "reveal()" --include="*.kt"`

## 4. 실행 요약

```bash
./gradlew check        # 가드레일 전부 + 오프라인 검증 전부. 항상 통과해야 한다
./gradlew liveTest     # 키움 모의서버 스모크. KIWOOM_APP_KEY 없으면 skip (예정)
```
